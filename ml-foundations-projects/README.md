# ML Foundations Projects

A collection of foundational machine learning notebooks and reports covering supervised learning, regression, ensemble learning, and unsupervised learning.

## Projects

| Project | Contents |
|---|---|
| Classification | Decision Tree classification workflow with preprocessing, evaluation metrics, confusion matrix, ROC curve, and report. |
| Regression | Regression workflow on concrete strength data with Linear Regression and Random Forest Regressor evaluation. |
| Random Forest Ensemble | Random Forest classification on Adult Census Income with preprocessing pipelines, evaluation metrics, confusion matrix, ROC curve, and feature importance. |
| SOM Unsupervised Learning | Self Organizing Map analysis on Parkinson's data with preprocessing, SOM training, U-Matrix/component visualizations, PCA, quantization error, and topographic error. |

## Skills Demonstrated

- Data preprocessing and feature scaling
- Classification and regression model training
- Model evaluation with accuracy, precision, recall, F1, ROC/AUC, MAE, MSE, RMSE, and R2
- Decision Trees, Random Forests, Linear Regression, and Self Organizing Maps
- Data visualization with Matplotlib and Seaborn
- Report writing and ML workflow documentation

## Tech Stack

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, MiniSom, Jupyter Notebook
